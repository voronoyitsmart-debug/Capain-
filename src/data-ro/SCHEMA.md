# Формат учебных данных — румынский язык

Приложение «Română zi de zi» учит румынскому русскоговорящих. Каждый файл в `data-ro/` —
обычный JS-файл, который добавляет элементы в глобальный объект `DE` (имя историческое,
создаётся в `data-ro/_init.js`):

```js
DE.topics.push(
  { ... },
  { ... }
);
```

Никаких import/export. Строки — в двойных кавычках или обратных (template literals) для
длинного HTML. Язык пояснений — русский. Уровни: "A1", "A2", "B1", "B2", "C1"
(по CEFR; ориентир — учебники румынского как иностранного и экзамен Института румынского языка).

**Орфография:** только современная норма: ș и ț с запятой снизу (U+0219, U+021B), НЕ ş/ţ с седилью;
â внутри слова, î в начале и конце (sunt, România, încă, a hotărî); диакритика везде обязательна.

Проверка: `node tools/validate.js data-ro/<файл>.js`

## DE.topics — словарные темы

```js
{
  id: "food",                 // уникальный, латиница, snake_case
  title: "Еда",               // по-русски
  ro: "Mâncare",              // название темы по-румынски
  emoji: "🍎",
  level: "A1",                // уровень, к которому относится большинство слов темы
  words: [
    // существительное: ro — ед. ч. без артикля, g — род, pl — мн. ч. без артикля, def — с определённым артиклем
    { ro: "măr", g: "m", pl: "mere", def: "mărul", ru: "яблоко", t: "n", lvl: "A1",
      ex: "Mănânc un măr în fiecare dimineață.", exRu: "Я каждое утро ем яблоко." },
    { ro: "casă", g: "f", pl: "case", def: "casa", ru: "дом", t: "n", lvl: "A1", ex: "...", exRu: "..." },
    { ro: "tren", g: "n", pl: "trenuri", def: "trenul", ru: "поезд", t: "n", lvl: "A1", ex: "...", exRu: "..." },
    // глагол — инфинитив с «a»
    { ro: "a mânca", ru: "есть, кушать", t: "v", lvl: "A1", ex: "Mâncăm la ora șapte.", exRu: "Мы едим в семь часов." },
    // прилагательное — мужской род ед. ч.; forms — 4 формы: м. ед., ж. ед., м. мн., ж. мн.
    { ro: "frumos", forms: "frumos, frumoasă, frumoși, frumoase", ru: "красивый", t: "adj", lvl: "A1", ex: "...", exRu: "..." },
    { ro: "Poftă bună!", ru: "Приятного аппетита!", t: "phr", lvl: "A1", ex: "...", exRu: "..." }
  ]
}
```

- `t`: "n" (существительное), "v" (глагол), "adj", "adv", "phr" (фраза/выражение), "other".
- Для `t:"n"` обязательны `g` ("m" — мужской, "f" — женский, "n" — средний/neutru), `pl`
  (форма мн. ч. без артикля; "-" если не бывает) и `def` (ед. ч. с определённым артиклем: mărul, casa, trenul).
  Существительное только во множественном числе: `ro` — форма мн. ч., `pl: "-"`, в `ru` пометка «(мн.)».
- `forms` у прилагательных — если формы не образуются тривиально (необязательно, но желательно).
- `ex` — короткое естественное предложение (4–12 слов), `exRu` — перевод. Пример обязателен.
- `ru` — основные значения через запятую (1–3). Если два слова темы переводятся одинаково,
  уточните в скобках: «дорога (путь)» / «дорога (улица)».
- `alt` (необязательно) — другие правильные ответы для упражнения «Письмо»: настоящие синонимы
  и варианты написания, например `alt: ["autobuz"]`.
- В теме 35–50 слов, без дубликатов внутри темы.

## DE.grammar — уроки грамматики

```js
{
  id: "articol_hotarat",
  title: "Определённый артикль (-ul, -a, -le)",
  level: "A1",
  emoji: "🎯",
  summary: "Артикль пишется в конце слова: pom → pomul, casă → casa",   // 1 строка
  content: `<p>HTML-объяснение по-русски…</p>
            <table><tr><th>…</th></tr>…</table>
            <div class="tip">Совет / лайфхак</div>
            <div class="ex"><b>Văd trenul.</b> — Я вижу поезд.</div>`,
  exercises: [
    { type: "choice", q: "Unde este ___? (casă, с артиклем)", options: ["casa", "casă", "casei"], a: 0,
      explain: "Женский род на -ă: определённый артикль -a заменяет -ă: casă → casa." },
    { type: "input", q: "Am cumpărat ___ (pâine, с артиклем).", a: ["pâinea"],
      explain: "Слова на -e получают -a: pâine → pâinea." },
    { type: "order", words: ["Eu", "citesc", "o", "carte"], ru: "Я читаю книгу.",
      alts: [["Citesc", "o", "carte", "eu"]], explain: "Обычный порядок: подлежащее — глагол — дополнение." }
  ]
}
```

- В `content` разрешены теги: p, b, i, u, br, ul, ol, li, table, tr, th, td, h3, h4,
  `<div class="tip">`, `<div class="ex">`, `<div class="warn">`, `<span class="hl">`.
- `choice`: `a` — индекс правильного варианта, ровно ОДИН вариант правильный.
  `input`: `a` — массив ВСЕХ допустимых ответов. `order`: `words` в ПРАВИЛЬНОМ порядке, `ru` — перевод,
  `alts` (необязательно) — другие правильные порядки тех же слов (в румынском порядок свободнее — указывайте их!).
- `explain` ОБЯЗАТЕЛЕН у каждого упражнения: 1–2 предложения, почему верно именно так.
- 10–14 упражнений на урок, все три типа вперемешку.

## DE.tests — банк вопросов для тестов

```js
{ lvl: "A2", cat: "grammar", q: "Ieri ___ la cinema.", options: ["am mers", "merg", "voi merge", "mergeam"], a: 0,
  explain: "«Ieri» — законченное действие в прошлом: perfect compus (am mers)." }
```

- `cat`: "grammar" | "vocab" | "reading" (короткий текст 1–3 предложения в q + вопрос) | "usage".
- Ровно 4 варианта, ровно один правильный, `a` — его индекс; позиции правильных ответов распределять равномерно.
- `explain` обязателен.

## DE.verbs — спряжение

```js
{ inf: "a merge", ru: "идти", lvl: "A1", group: "III",       // спряжение: "I" (-a), "II" (-ea), "III" (-e), "IV" (-i/-î)
  prez:   ["merg", "mergi", "merge", "mergem", "mergeți", "merg"],      // eu tu el/ea noi voi ei/ele
  imperf: ["mergeam", "mergeai", "mergea", "mergeam", "mergeați", "mergeau"],
  part: "mers",                 // participiu: perfect compus = am/ai/a/am/ați/au + part
  conj: "să meargă",            // conjunctiv, 3-е лицо (el/ea, ei/ele)
  imp: "mergi!",                // императив 2 л. ед. ч. (утвердительный); "" если нет
  ex: "Mâine merg la munte.", exRu: "Завтра я еду в горы." }
```
Возвратные глаголы: `inf: "a se spăla"`, формы с местоимением: "mă spăl", "te speli", "se spală",
"ne spălăm", "vă spălați", "se spală"; imperf так же; `part: "spălat"` (perfect compus: m-am spălat —
приложение само его не строит для возвратных, поэтому добавьте поле `perf: ["m-am spălat", "te-ai spălat",
"s-a spălat", "ne-am spălat", "v-ați spălat", "s-au spălat"]`). Поле `perf` (6 форм) можно указывать и у
любого другого глагола — тогда оно используется вместо автоматического.

## DE.dialogues — диалоги

```js
{ id: "cafe_order", title: "В кафе", emoji: "☕", lvl: "A1",
  context: "Вы заказываете кофе и пирожное.",
  lines: [
    { s: "Ospătar", ro: "Bună ziua! Ce doriți?", ru: "Добрый день! Что желаете?" },
    { s: "Client", ro: "O cafea, vă rog.", ru: "Кофе, пожалуйста." }
  ],
  quiz: [ { q: "Что заказал гость?", options: ["Чай", "Кофе", "Сок", "Воду"], a: 1,
            explain: "Гость говорит: „O cafea, vă rog“ — кофе." } ] }
```
8–16 реплик, 3–4 вопроса (вопросы и варианты — по-русски), у каждого вопроса `explain` со ссылкой на реплику.

## DE.reading — тексты для чтения

```js
{ id: "ziua_mea", title: "Ziua mea", ru: "Мой день", lvl: "A1", emoji: "☀️",
  text: "Абзацы через \n\n. Румынский текст.",
  glossary: [ { ro: "a se trezi", ru: "просыпаться" } ],    // 5–10 трудных слов
  questions: [ { q: "Во сколько Ана просыпается?", options: ["...", "...", "...", "..."], a: 0,
                 explain: "В тексте: „Ana se trezește la ora șapte“ — в семь." } ] }  // 4–5 вопросов
```
Длина текста: A1 ~80–120 слов, A2 ~120–180, B1 ~180–250, B2 ~250–330, C1 ~300–400.
