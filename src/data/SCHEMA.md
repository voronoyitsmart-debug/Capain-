# Формат учебных данных

Каждый файл в `data/` — обычный JS-файл, который добавляет элементы в глобальный объект `DE`
(создаётся в `data/_init.js`). Файл должен выглядеть так:

```js
DE.topics.push(
  { ... },
  { ... }
);
```

Никаких import/export, никаких внешних зависимостей. Строки — в двойных кавычках
или обратных (template literals) для длинного HTML. Язык пояснений — русский.
Уровни: "A1", "A2", "B1", "B2", "C1".

Проверка: `node tools/validate.js data/<файл>.js`

---

## DE.topics — словарные темы

```js
{
  id: "food",                 // уникальный, латиница, snake_case
  title: "Еда и напитки",     // по-русски
  de: "Essen und Trinken",    // название по-немецки
  emoji: "🍎",
  level: "A1",                // основной уровень темы
  words: [
    // существительное: артикль обязателен в поле de, мн. число в pl ("-" если нет мн. числа)
    { de: "der Apfel", pl: "die Äpfel", ru: "яблоко", t: "n", lvl: "A1",
      ex: "Ich esse jeden Morgen einen Apfel.", exRu: "Я каждое утро ем яблоко." },
    // глагол
    { de: "essen", ru: "есть, кушать", t: "v", lvl: "A1",
      ex: "Wir essen um sieben Uhr.", exRu: "Мы едим в семь часов." },
    // прилагательное / наречие / фраза / прочее
    { de: "lecker", ru: "вкусный", t: "adj", lvl: "A1", ex: "...", exRu: "..." },
    { de: "Guten Appetit!", ru: "Приятного аппетита!", t: "phr", lvl: "A1", ex: "...", exRu: "..." }
  ]
}
```

- `t`: "n" (существительное), "v" (глагол), "adj", "adv", "phr" (фраза/выражение), "other".
- Для `t:"n"` поле `de` ОБЯЗАТЕЛЬНО начинается с "der ", "die " или "das ", а `pl` — форма
  мн. числа с "die " (или "-" если не бывает мн. числа / только мн. число — тогда в de "die ... (Pl.)").
- `ex` — короткое естественное предложение-пример (4–12 слов), `exRu` — его перевод.
  Пример обязателен у каждого слова (используется в упражнении «собери предложение»).
- `ru` — краткий перевод (1–3 варианта через запятую).
- В теме 35–50 слов, без дубликатов внутри темы.
- `level` темы = уровень, к которому относится большинство слов темы.
- `lvl` слова — по спискам Goethe-Institut / telc (Wortliste A1, A2, B1; для B2–C1 — Profile Deutsch и частотность).
- `alt` (необязательно) — другие правильные немецкие ответы для упражнения «Письмо»:
  синонимы с тем же переводом и варианты написания, например `alt: ["der Doktor"]` у `der Arzt`.
- `ru` — перечисляйте основные значения через запятую; если два слова темы переводятся одинаково,
  уточните в скобках: «дорога (путь)», «дорога (улица)».

## DE.grammar — уроки грамматики

```js
{
  id: "akkusativ",
  title: "Винительный падеж (Akkusativ)",
  level: "A1",
  emoji: "🎯",
  summary: "Кого? Что? — den/einen, mich/dich…",   // 1 строка
  content: `<p>HTML-объяснение по-русски…</p>
            <table><tr><th>…</th></tr>…</table>
            <div class="tip">Совет / лайфхак</div>
            <div class="ex"><b>Ich sehe den Mann.</b> — Я вижу мужчину.</div>`,
  exercises: [
    { type: "choice", q: "Ich sehe ___ Hund.", options: ["der", "den", "dem"], a: 1,
      explain: "Akkusativ мужского рода: der → den." },
    { type: "input", q: "Er kauft ___ Buch. (ein)", a: ["ein"],
      explain: "Средний род в Akkusativ не меняется." },
    { type: "order", words: ["Ich", "kaufe", "heute", "einen", "Tisch"], ru: "Я сегодня покупаю стол.",
      explain: "Глагол на втором месте." }
  ]
}
```

- В `content` разрешены теги: p, b, i, u, br, ul, ol, li, table, tr, th, td, h3, h4,
  `<div class="tip">`, `<div class="ex">`, `<div class="warn">`, `<span class="hl">`.
- `choice`: `a` — индекс правильного варианта. `input`: `a` — массив ВСЕХ допустимых ответов
  (сравнение без учёта регистра и лишних пробелов). `order`: `words` в ПРАВИЛЬНОМ порядке
  (приложение само перемешает), `ru` — перевод, `alts` (необязательно) — массив других
  правильных порядков тех же слов, например `alts: [["Heute", "kaufe", "ich", "einen", "Tisch"]]`.
- `explain` ОБЯЗАТЕЛЕН у каждого упражнения: 1–2 предложения, почему верно именно так
  (и, если уместно, почему типичный неверный вариант не подходит).
- 10–14 упражнений на урок, все три типа вперемешку.

## DE.tests — банк вопросов для тестов

```js
{ lvl: "A2", cat: "grammar", q: "Gestern ___ ich ins Kino gegangen.",
  options: ["habe", "bin", "war", "wurde"], a: 1,
  explain: "gehen образует Perfekt с sein." }
```

- `cat`: "grammar" | "vocab" | "reading" (короткий текст 1–3 предложения прямо в q + вопрос) | "usage".
- `explain` обязателен: почему правильный ответ верен (правило / значение слова).
- Ровно 4 варианта, `a` — индекс правильного. Правильные ответы распределять по позициям равномерно.
- `q` может содержать русский текст ("Как сказать «я голоден»?").

## DE.verbs — спряжение

```js
{ inf: "fahren", ru: "ехать", lvl: "A1", type: "strong",     // "weak" | "strong" | "mixed" | "modal" | "irregular"
  sep: false,                                               // отделяемая приставка?
  praes: ["fahre", "fährst", "fährt", "fahren", "fahrt", "fahren"],   // ich du er wir ihr sie
  praet: ["fuhr", "fuhrst", "fuhr", "fuhren", "fuhrt", "fuhren"],
  perf: "ist gefahren",                                     // 3 л. ед. ч.: вспомогательный + Partizip II
  imp: "fahr!",                                             // du-форма императива ("" если нет)
  ex: "Ich fahre morgen nach Berlin.", exRu: "Завтра я еду в Берлин." }
```

Для отделяемых глаголов формы пишутся полностью: "stehe auf", "stehst auf"…

## DE.dialogues — диалоги

```js
{ id: "cafe_order", title: "В кафе", emoji: "☕", lvl: "A1",
  context: "Вы заказываете кофе и пирожное.",
  lines: [
    { s: "Kellner", de: "Guten Tag! Was darf es sein?", ru: "Добрый день! Что желаете?" },
    { s: "Gast", de: "Einen Kaffee, bitte.", ru: "Кофе, пожалуйста." }
  ],
  quiz: [ { q: "Что заказал гость?", options: ["Чай", "Кофе", "Сок", "Воду"], a: 1 } ] }
```
8–16 реплик, 3–4 вопроса (вопросы и варианты — по-русски). У каждого вопроса `explain` —
короткое объяснение со ссылкой на реплику: «Гость говорит: „Einen Kaffee, bitte“ — кофе».

## DE.phrases — разговорник

```js
{ id: "doctor", title: "У врача", emoji: "🩺", lvl: "A2",
  items: [ { de: "Ich habe Kopfschmerzen.", ru: "У меня болит голова." } ] }   // 15–25 фраз
```

## DE.reading — тексты для чтения

```js
{ id: "mein_tag", title: "Mein Tag", ru: "Мой день", lvl: "A1", emoji: "☀️",
  text: "Абзацы через \n\n. Немецкий текст.",
  glossary: [ { de: "aufstehen", ru: "вставать" } ],    // 5–10 трудных слов
  questions: [ { q: "Во сколько Анна встаёт?", options: ["...", "...", "...", "..."], a: 0,
                 explain: "В тексте: „Anna steht um sieben Uhr auf“ — в семь." } ] }  // 4–5 вопросов
```
Длина текста: A1 ~80–120 слов, A2 ~120–180, B1 ~180–250, B2 ~250–330, C1 ~300–400.
