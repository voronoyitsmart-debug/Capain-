# Capain — немецкий и румынский

Приложение для изучения языков A1–C1 для русскоговорящих: **https://voronoyitsmart-debug.github.io/Capain-/**

При входе выбираете язык — 🇩🇪 немецкий или 🇷🇴 румынский. Сменить язык можно в любой момент
(флаг в шапке или «Ещё» → «Язык»). Прогресс по каждому языку хранится отдельно.
Откройте ссылку в Safari → «Поделиться» → «На экран „Домой“» — дальше работает без интернета.

## Что умеет

- 48 тем, 2300+ слов, 11 тренажёров, интервальное повторение.
- **Адаптивная сложность прямо по ходу заданий**: каждый верный ответ — следующее задание сложнее
  (больше вариантов, похожие слова, письмо, диктант; в грамматике — от выбора к вводу и порядку слов;
  в глаголах — от настоящего времени к прошедшим). Если видно, что реально трудно (две ошибки подряд
  или три из пяти), приложение откатывает на уровень назад и сразу повторяет проблемное слово попроще.
  Оно же предлагает перейти на следующий уровень A1 → A2… или вернуться на предыдущий.
- **Разбор каждой ошибки**: что значит выбранный вариант, где ошибка в написании, правило рода,
  множественного числа, спряжения и порядка слов; кнопка «Правило» в грамматике.
- Синонимы и варианты написания принимаются; кнопка «Мой ответ тоже верный» запоминает ваш вариант.
- 45 уроков грамматики, ~320 тестовых вопросов, тест на уровень, экзамены, 170 глаголов,
  30 текстов, 28 диалогов, разговорник.

## Устройство репозитория

- Корень — собранное приложение (его публикует GitHub Pages): общий `app.js` и данные языков `data-de.js`, `data-ro.js`.
  Руками не править. `ro/` — перенаправление со старого адреса румынской версии.
- `src/` — исходники, общие для обоих языков:
  - `js/` — логика, `css/` — стили;
  - `lang/de.js`, `lang/ro.js` — всё, что зависит от языка (род и артикли, диакритика, спряжение,
    правила для объяснений ошибок, подписи);
  - `data/` — немецкий контент (формат — `src/data/SCHEMA.md`), `data-ro/` — румынский (`src/data-ro/SCHEMA.md`);
  - `tools/` — проверка и сборка.

```
node src/tools/validate.js      # проверка учебных данных обоих языков
node src/tools/build.js         # сборка приложения в корень репозитория
```
