# Capain · Deutsch Tag für Tag · Română zi de zi

Приложения для изучения языков A1–C1 для русскоговорящих:

- 🇩🇪 немецкий — **https://voronoyitsmart-debug.github.io/Capain-/**
- 🇷🇴 румынский — **https://voronoyitsmart-debug.github.io/Capain-/ro/**

Откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». Дальше работает без интернета,
прогресс хранится на телефоне — у каждого языка свой.

## Что умеет

- 48 тем, 2300+ слов, 11 тренажёров, интервальное повторение.
- **Адаптивная сложность**: верные ответы — задания сложнее (больше вариантов, похожие слова,
  письмо и диктант), ошибки — шаг назад. Приложение само предлагает перейти на следующий уровень
  или вернуться на предыдущий.
- **Разбор каждой ошибки**: что значит выбранный вариант, где ошибка в написании, правило рода,
  множественного числа, спряжения и порядка слов; кнопка «Правило» в грамматике.
- Синонимы и варианты написания принимаются; кнопка «Мой ответ тоже верный» запоминает ваш вариант.
- 45 уроков грамматики, ~320 тестовых вопросов, тест на уровень, экзамены, 170 глаголов,
  30 текстов, 28 диалогов, разговорник.

## Устройство репозитория

- Корень — собранный немецкий сайт, `ro/` — собранный румынский (их публикует GitHub Pages). Руками не править.
- `src/` — исходники, общие для обоих языков:
  - `js/` — логика, `css/` — стили;
  - `lang/de.js`, `lang/ro.js` — всё, что зависит от языка (род и артикли, диакритика, спряжение,
    правила для объяснений ошибок, подписи);
  - `data/` — немецкий контент (формат — `src/data/SCHEMA.md`), `data-ro/` — румынский (`src/data-ro/SCHEMA.md`);
  - `tools/` — проверка и сборка.

```
node src/tools/validate.js      # проверка учебных данных обоих языков
node src/tools/build.js         # сборка обоих сайтов (или: build.js de / build.js ro)
```
