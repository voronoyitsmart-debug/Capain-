# Kvizora — инструкция владельца

> Только для владельца сервиса. Учителям и ученикам архив не передавайте: они открывают адрес Kvizora в браузере.
> Код закрыт, см. `LICENSE`. Чужие лицензии: `THIRD-PARTY-NOTICES.txt` (в программе — страница «Ліцензії»).

## 1. Запуск (один раз настроить)

1. Установите **Node.js 22.13+** (https://nodejs.org, кнопка LTS).
2. Распакуйте архив, откройте папку в терминале:
   ```
   npm install
   npm start
   ```
3. На **этом же компьютере** откройте http://localhost:3000/setup: школа, ваше имя, e-mail, пароль, две галочки. Вы — администратор.
4. Адрес для всех появится в консоли («Інтернет-адреса…») и в кабинете. Компьютер не должен спать, пока идут тесты.

**Постоянный адрес** (рекомендуется): создайте именованный туннель в Cloudflare Zero Trust и впишите в `.env`
`CLOUDFLARE_TUNNEL_TOKEN=...` и `PUBLIC_URL=https://ваш-домен`. Без этого адрес `*.trycloudflare.com` меняется после каждого перезапуска.

Прочее в `.env` (образец — `.env.example`): `GEMINI_API_KEY` (тест из фото), `PORT`.

## 2. Как это работает

- **Аккаунты создаёт только администратор** (адмін-панель): школы → классы → ученики (логины и пароли печатаются листочками) → учителя (временный пароль, при первом входе свой пароль + принятие Условий).
- Ученик входит и видит тесты своего класса по предметам; нет тестов — ❌.
- Учитель в редакторе выбирает «для класів» или «для всієї школи», а в «Розклад → 🛡 Безпека» — меры против списывания и «можна без акаунта (за кодом)».
- Журнал оценок: кабинет → «📒 Оцінки».
- Правильные ответы и проверка — только на сервере. Код в браузере сжат, исходники сервер не отдаёт. Полностью скрыть код страницы в браузере невозможно (так устроен веб), но логики и ответов там нет.

### Тест из учебника (📚 Підручники)
Кабинет → «📚 Підручники»: учитель или админ добавляет учебник школы (PDF или фото страниц), Kvizora делит его на темы (закладки PDF, оглавление или «🤖 Знайти теми»), учитель отмечает темы → «✨ Створити тест» → черновик в предмете, открывается в редакторе.
- Сам PDF на сервер не загружается: браузер читает текст страниц. Хранятся только текст и уменьшенные картинки страниц без текста (сканы, фото) — в `data/tests.db`.
- Учебники видят только учителя и админ своей школы, ученики — нет. Менять/удалять — кто добавил или админ.
- В Gemini уходят только страницы выбранных тем (до ~30 страниц текста или 10 картинок). Лимит: `BOOKS_AI_PER_DAY` запросов на школу в сутки (по умолчанию 300).
- Сканы и фото — бета: ИИ ошибается чаще, особенно в формулах. Тест всегда черновик, учитель проверяет.

- **Журнал рядом с «Мрією».** «📒 Журнал» → «📅 За датами»: тема урока под датой, «н» и «нп» (без причины), столбец «Пропуски». «🏁 Підсумкові»: тематические, семестровые и годовая оценки ставит учитель, серая цифра лишь подсказка. «⬇️ Excel» скачивает журнал класса (CSV для Excel), чтобы перенести оценки в официальный журнал; каждая выгрузка пишется в журнал действий.
- **Батьки.** Выключено по умолчанию. Админ школы: «Дані й право» → «👪 Доступ батьків», затем «Учні» → «👪 Код батькам» (код показывается один раз, действует год, в базе только хэш). Родитель открывает `/parent` («Я з батьків» на странице входа) и видит только своего ребёнка, без возможности что-то менять. Код отзывается кнопкой «Відкликати код», новым кодом или выключением доступа для школы.
- **Банк школи.** Учитель: «⋯» у теста → «🏫 Поділитися з колегами школи». Коллеги той же школы: «🏫 Банк школи» → «Скопіювати собі» (черновик в папке «Від колеги: …»). Результаты учеников не передаются.

## 3. Юридическое (до работы с учениками)

Адмін-панель → «⚖️ Дані й право»: реквизиты школы, ваши контакты, сроки хранения (данные устройств — 90 дней по умолчанию, чистятся автоматически).
Классы → галочка «Батьків поінформовано» после сбора согласий (бланки — `LEGAL/consent-forms.md`).
Тексты в `LEGAL/` — черновики, их должен проверить юрист.

## 4. Обслуживание

- **Резервная копия:** остановите сервер и скопируйте папку `data/` (файл `tests.db` и фото домашних заданий `hw-files/`). Храните копии не дольше 30 дней: в них есть данные учеников, а фото в самой программе удаляются через 30 дней.
- **Забыли пароль администратора:** `npm run reset-password -- ваш@email` (на этом компьютере).
- **Обновление:** замените файлы программы, `data/` и `.env` не трогайте, затем `npm install` и `npm start`.

## 5. Ярлык на телефоне

Откройте адрес Kvizora в браузере телефона:
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» (или кнопка «Встановити» внизу страницы).
- **iPhone (Safari):** «Поделиться» → «На экран «Домой»».

Ярлык откроется как отдельное приложение.
